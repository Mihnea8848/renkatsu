# Changelog

Each section is also the text of the matching GitHub release.

## Unreleased

No release yet. Characters render from the command line and are compared with
captures from CharaStudio.

### Added

- Card, coordinate and Unity bundle readers, the content index with
  Sideloader's item resolution, and character assembly with sliders
- The game's shaders for skin, hair, eyes, face lines and clothes, ported from
  the compiled shaders, in linear colour
- Draw order and stencil from each shader's own passes, with the Hair Shadows
  Fix and Better Repack defaults for eyes and brows
- Plugin data: overlays, MaterialEditor, MoreAccessories, ABMX, Hair
  Accessory Customizer and Pushup
- `rk reference`, which renders a card with the camera and light of a game
  capture and writes both side by side with their difference
