# Skin effect pictures

These pictures come from the KK_SkinEffects plugin ("Additional Skin
Effects", `Marco.SkinEffects` 3.0.1, by ManlyMarco), where they are built
into the plugin as `KK_SkinEffects.Resources.<Kind>_<level>.png`.

The plugin is released under GPL-3.0, and so are these pictures. The license
